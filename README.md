+Cuidado es una aplicación en proceso para presentar en nuestro proyecto modular. Se trata de una Web-App pensada para aquellas personas encargadas de cuidar mascotas, ayudándoles a mantener una buena gestión con los recordatorios, ya sea de citas veterinarias, vacunas, medicamentos, horas de comida y paseo, etc.

## Funciones principales de +Cuidado
- Calendario: Para programar recordatorios de citas veterinarias.
- Mapa: Muestra de un mapa de la ubicación del usuario destacando las veterinarias cercanas.
- Cartilla virtual: Incluye información de la mascota, raza, sexo, edad, vacunas aplicadas, etc.
- Historial clínico: Va de la mano con la cartilla, para tener un control de los cuidados que ha recibido la mascota.
